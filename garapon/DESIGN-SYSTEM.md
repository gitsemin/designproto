# GARAPON³ᴸ 디자인시스템 v2.0

레퍼런스: analogue.co (Analogue³ᴰ "Shipping Now"). 스튜디오 회색과 검정 화면을 번갈아 쓰고, 가운데에 큰 제품 사진을 두고, 이름 뒤에 작은 위첨자를 붙이고(Analogue³ᴰ → GARAPON³ᴸ, L = Light), 제목은 무게 500에 촘촘한 자간, 문단은 두 톤(첫 문장 흰색, 나머지 회색)으로 쓰는 방식을 가져왔다. 포인트 컬러는 analogue의 노랑(#F4CD01)으로, 가라폰의 노란 반투명 몸통과 같은 색이라 그대로 쓴다.

## 1. 브랜드 원칙

1. **물건이 주인공.** 화면 한가운데 램프 하나를 크게. 글자는 위아래로 비켜선다.
2. **조용한 회색, 깊은 검정.** 소개는 스튜디오 회색, 기술·체험은 검정 화면에서.
3. **노랑은 빛에만.** 노랑은 램프가 켜진 상태, 새 소식 띠, 밝기 게이지에만. 버튼은 흑백.
4. **한 문단, 두 톤.** 첫 문장만 밝게 써서 요점을 먼저 읽게 한다.
5. **작게 말하고 크게 보여 준다.** 메뉴·라벨은 13px로 작게, 사진과 제목은 크게.

## 4. 간격 · 반경 · 선

- 간격(4 배수): 4, 8, 12, 16, 24, 32, 48, 64, 96, 160. 화면 위아래 여백 160(모바일 96).
- 반경: 알약 999(버튼, 페이지 점), 카드 10(기능·후기 카드), 사진 16.
- 선: 1px만. 그림자는 쓰지 않는다. 깊이는 회색·검정·ink 세 면으로만.

## 5. 브레이크포인트 · 그리드

| 이름 | 폭 | 그리드 |
| --- | --- | --- |
| mobile | ~767 | 4열, 여백 20 |
| tablet | 768~1199 | 8열, 여백 40 |
| desktop | 1200~ | 12열, 최대 1280, 간격 24 |

**섹션 구성 규칙**
- 화면 하나 = 이야기 하나. 가운데 정렬이 기본, 기술 문단만 2단.
- 기본 순서: 첫 화면(회색) → 공지 띠(검정) → 이야기(검정) → 3D 조립(검정, 스크롤) → 체험(검정) → 기능 카드(검정) → 갤러리(회색) → 노랑 띠 → 소식·푸터(검정).
- 회색에서 검정으로 넘어갈 때 경계는 바로 자른다(그라데이션 없음).

## 7. 컴포넌트

### 버튼
| 종류 | 모양 | 상태 |
| --- | --- | --- |
| Primary | 알약. 회색 위: 검정 바탕·흰 글자 / 검정 위: 흰 바탕·검정 글자. 높이 44, 좌우 24, 글자 15/500 | hover: 노랑 바탕·검정 글자 / active: 투명도 80% / focus: 2px 노랑 링 / disabled: 30% |
| Secondary | 알약 외곽선 1px 현재 글자색, 바탕 없음 | hover: 바탕 채움 |
| Utility | 글자 + 1px 밑줄, 13~15px | hover: 노랑 밑줄 |

### 입력 필드 · 텍스트 영역
- 검정 화면용(analogue 뉴스레터 방식). 라벨 small grey-400, 입력칸은 바탕 없이 아래 선 1px grey-600, 높이 44, 오른쪽 끝에 Utility 버튼("구독").
- 포커스: 아래 선 노랑. 오류: 아래 선 노랑 + 도움말 노랑 + 앞에 "!" (빨강은 쓰지 않는다).
- 텍스트 영역: 상자형, 1px grey-700 테두리, 반경 10, 최소 높이 120.

### 기능 카드 (프로젝트 카드)
- 검정 화면 위 흰 카드, 반경 10, 안쪽 16. 위 그림 영역 1:1(흰 바탕에 검정 선 그림) → 제목 18/500 → 설명 13.
- 데스크톱 4장 한 줄(3열 폭). 새 항목만 왼쪽 위 노랑 "New" 알약 태그(11px).

### 후기 카드
- 검정 위 ink 카드, 반경 10, 1px grey-700 선. 왼쪽 위 점수(h2), 오른쪽 위 출처(small), 아래 인용문(small).

### 공지 띠 (Ticker)
- 검정 바탕, 높이 32, 흰 13px 글자가 왼쪽으로 흐른다. "New! …" 문장 반복.

### 이름 위첨자 줄 (Kicker)
- "GARAPON<sup>L</sup>" kicker 크기, 바로 아래 h1 제목.

### 페이지 점
- 지름 20 원, 번호. 현재 페이지는 채움(회색 위 검정 / 검정 위 흰색), 나머지는 30% 투명도.

## 8. 사용 가이드와 정책

- 제품 사진은 스튜디오 회색 배경 사진만. 사진 배경이 화면 바탕과 이어지게 회색 화면 위에 둔다.
- 노랑으로 글자를 칠하지 않는다. 노랑은 면(띠, 태그, 게이지)으로만 쓰고, 그 위 글자는 검정.
- grey-600은 검정 위 글자로 쓰지 않는다(3.3:1).
- 버튼 문구는 두 단어 이하: "돌려 보기", "구독".
- 이모지 대신 1.5px 선 아이콘.
- 문서와 다른 값이 필요하면 코드보다 문서를 먼저 고친다.

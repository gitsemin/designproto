# GARAPON / LIGHT 디자인시스템 v1.0

레퍼런스: play.date (Panic). 장난감 같은 하드웨어를 진지하게 소개하는 말투, 화면 전체를 칠하는 색 띠, 굵은 제목 끝의 마침표, 비스듬히 붙인 스티커 태그를 가져왔다. playdate의 보라 포인트는 가라폰 램프의 노란 몸통과 맞지 않아 **주황(#EF5023)** 으로 바꿨다. 주황은 playdate 사이트 안에도 이미 있는 색이다.

## 1. 브랜드 원칙

1. **돌리는 손이 주인공.** 화면의 모든 조작은 "돌린다, 멈춘다"로 설명한다. 크랭크·다이얼·회전 화살표가 반복 모티프.
2. **색 띠 한 장 = 이야기 하나.** 섹션마다 바탕색을 통째로 바꾸고, 띠 안에는 제목 하나와 내용 하나만 둔다.
3. **제목은 마침표로 끝낸다.** "The Crank." "돌리면, 밝아진다." 짧게 말하고 멈춘다.
4. **스티커는 한 화면에 하나.** 비스듬한 검은 태그는 새 소식이나 핵심 숫자 하나에만 붙인다.
5. **빛은 노랑, 행동은 주황.** 노랑은 램프의 빛(상태·배경), 주황은 누를 수 있는 것(버튼·링크)에만 쓴다.

## 3. 타이포그래피

글꼴: **Pretendard** (playdate의 Roobert를 한글로 옮긴 대체. 둥글고 기하학적인 산세리프). 숫자 스펙은 `font-variant-numeric: tabular-nums`.

| 이름 | 크기/행간 | 굵기 | 쓰임 |
| --- | --- | --- | --- |
| display | 96/92 | 800 | 히어로 로고타입 "가라폰" |
| h1 | 56/60 | 800 | 띠 제목 (마침표로 끝) |
| h2 | 32/38 | 700 | 카드 제목, 하위 제목 |
| lead | 22/32 | 700 | 띠 첫 문단 |
| body | 17/28 | 400 | 본문 |
| small | 14/20 | 500 | 캡션, 입력 라벨 |
| sticker | 15/18 | 800 | 스티커 글자 (숫자는 28) |

## 4. 간격 · 반경 · 그림자

- 간격(4 배수): 4, 8, 12, 16, 24, 32, 48, 64, 96. 띠 위아래 여백 96(모바일 64).
- 반경: `--r-sticker` 6, `--r-card` 16, `--r-field` 12, `--r-pill` 999.
- 그림자: 스티커와 떠 있는 카드에만 `0 6px 0 rgba(0,0,0,.18)`. 흐린 그림자는 쓰지 않는다(장난감처럼 딱딱한 그림자).

## 5. 브레이크포인트 · 그리드

| 이름 | 폭 | 그리드 |
| --- | --- | --- |
| mobile | ~767 | 4열, 여백 20, 간격 16 |
| tablet | 768~1199 | 8열, 여백 40, 간격 24 |
| desktop | 1200~ | 12열, 최대 1200, 간격 24 |

**섹션 구성 규칙**
- 띠는 화면 전체 폭. 안쪽 내용은 최대 1200, 글 단락은 최대 640.
- 띠 순서: 히어로(steel) → 이야기 띠(yellow) 2~3개 → 손으로 해보기(paper) → 스펙(night) → 푸터(night).
- 같은 색 띠를 연달아 두지 않는다.

## 6. 모션

| 이름 | 값 | 쓰임 |
| --- | --- | --- |
| snap | 120ms, ease-out | 버튼 눌림(아래로 4px) |
| turn | 240ms, cubic-bezier(.2,.8,.2,1) | 다이얼·게이지 값 변화 |
| wobble | 600ms, 스티커 -8° ↔ -4° | 스티커에 마우스를 올릴 때 한 번 |
| glow | 밝기 값에 따라 0~1 | 램프 사진 위 빛 번짐 |

`prefers-reduced-motion`이면 wobble과 glow 변화를 끈다.

## 7. 컴포넌트

### 버튼
| 종류 | 모양 | 상태 |
| --- | --- | --- |
| Primary | 주황 알약, 흰 글자 19/700, 높이 52, 좌우 24, 앞에 아이콘 선택 | hover: orange-deep / active: 아래로 4px, 그림자 0 / focus: 3px 주황 링 + 2px 흰 틈 / disabled: 40% |
| Secondary | 잉크 알약, 흰 글자 | 같음 |
| Utility | 바탕 없음, 잉크 글자 + 2px 밑줄 | hover: 주황 글자 |

### 입력 필드 · 텍스트 영역
- 라벨(small, 위) + 칸(paper, 테두리 2px line, 반경 12, 높이 48, 안쪽 16) + 도움말(small, steel).
- focus: 테두리 orange. 오류: 테두리 orange-deep + 도움말 글자 orange-deep.
- 텍스트 영역: 최소 높이 120, 세로 크기 조절만.

### 프로젝트 카드
- 폭: 그리드 4열(데스크톱 3장 한 줄). 반경 16, 바탕 paper, 안쪽 24.
- 위: 이미지 4:3, 반경 12. 아래: 번호(small, steel) → 제목(h2) → 한 줄 설명(body) → Utility 버튼.
- 새 항목에만 스티커 하나(오른쪽 위, -8°).

### 스티커 태그
- night 바탕, 반경 6, 안쪽 8×12, 회전 -8°, 딱딱한 그림자.
- 글자 white 800, 핵심 숫자만 yellow 28.
- 한 화면에 하나.

### 밝기 다이얼 (가라폰 전용)
- 원형 눈금 0~4.5바퀴, 노랑 게이지 호, 가운데 % 숫자(h1).
- 센서 시리얼 값(회전 각도)이나 드래그로 돌린다.

## 8. 사용 가이드와 정책

- 노랑 띠 위 글자는 ink만 쓴다(대비 8.6:1). 주황 위 글자는 white(대비 3.6:1)이므로 WCAG 큰 글자 기준인 19px 700 이상에서만 쓴다(버튼 글자가 19px인 이유). 회색(steel) 띠 위 흰 글자도 4.0:1이라 22px 이상 제목·리드에만 쓴다.
- 버튼 문구는 동사로 시작한다: "돌려 보기", "센서 연결".
- 사진은 밝은 회색 바탕 제품 사진만. 배경을 오려 띠 색 위에 얹는다.
- 이모지 대신 선 아이콘(2px, 둥근 끝)을 쓴다.
- 이 문서와 다른 값이 필요하면 코드보다 문서를 먼저 고친다.
